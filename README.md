# # On the Limited Utility of Academic Citations in Informal Online Gaming Discourse

**Borzo**  
Independent Researcher & Community Observer  

**DOI:** 10.48550/arXiv.2509.11337

## Abstract
The integration of academic literature into informal online discussions is frequently assumed
to improve discourse quality, rigor, and factual grounding. This paper critically evaluates
this assumption within NGI, a large Italian videogame forum.
